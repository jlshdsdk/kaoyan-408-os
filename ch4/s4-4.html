4.4 本章疑难点

1. 文件的物理分配方式的比较

连续、链接、索引三种物理分配方式（详见 4.2.6）的差异，集中在三个问题上：访问第 n 条记录要几次访盘？空间利用率高不高？文件增删扩展方不方便？系统对比见表。

分配方式访问第 n 条记录优点缺点
连续分配需访问磁盘 1 次顺序存取时速度快；文件定长时可根据文件起始地址及记录长度直接算出第 n 条记录的位置，支持随机（直接）访问文件存储要求连续的存储空间，会产生碎片，不利于文件的动态扩充
链接分配需访问磁盘 n 次可解决外存的碎片问题，提高外存空间的利用率，文件动态增长较方便只能按照文件的指针链顺序访问，查找效率低；指针信息的存放消耗外存空间
索引分配m 级索引需访问磁盘 m+1 次可以随机访问，文件易于增删索引表增加额外的存储空间开销；索引表的查找策略对文件系统效率影响较大

「访问第 n 条记录」的访盘次数可以这样理解：连续分配下，记录连续存放，第 n 条记录的物理位置由起始块号加记录长度直接换算得到，一次访盘即可读出；链接分配必须从链头开始边读边沿指针后移，第 n 次访盘才读到目标记录；索引分配则先读索引块（m 级索引须逐层读 m 次），最后一次读数据块，合计 m+1 次。

考点「访问第 n 条记录需几次访盘」是选择题的直接考法，务必记牢 1 次、n 次、m+1 次这三个数；另一类考法是优缺点配对，如「哪种方式不利于文件动态增长」（连续）、「哪种方式既能随机访问又便于增删」（索引）。注意结合 4.2.6 辨析：显式链接（FAT）由于 FAT 常驻内存，查链不占访盘次数，访问第 n 块实际只需 1 次访盘——这与表中隐式链接的 n 次形成对比，是常见的混合考查点。

2. 文件打开的过程描述

打开文件（open，见 4.2.7）的目的，是把文件的元数据从磁盘「搬」进内存并建立访问通道，避免之后每次读/写都重复检索目录。其内部过程分三步：

  1. 检索目录：要求打开的文件必须是已经创建的文件，它应已登记在文件目录中，否则打开出错。检索到指定文件后，把其磁盘 inode 复制到内存的活动 inode 表中。
  2. 核对打开方式：将参数 mode 所给出的打开方式，与活动 inode 中创建文件时记录的文件访问权限相比较，若合法，则此次打开操作成功。
  3. 登记表项并返回描述符：打开合法时，为文件分配用户打开文件表表项和系统打开文件表表项，并为后者设置初值，通过指针建立表项与活动 inode 之间的联系，再把文件描述符 fd 返回给调用者。

此后进程对该文件的读/写只须携带 fd，系统沿「用户打开文件表 → 系统打开文件表 → 活动 inode」的指针链即可定位文件，无须再检索目录——这正是「打开」操作的价值所在。术语上可与 4.2.7 的两级打开文件表对应起来：这里的「用户打开文件表」即进程（每个进程私有）的打开文件表，「活动 inode 表」即驻留内存的 inode 信息。

考点选择题常考三点：①open 的动作次序——检索目录、权限核对、分配表项并返回 fd，把顺序调换即为错误选项；②文件必须已创建才能打开，按 mode 打开而权限不符则打开失败；③打开成功后按 fd 访问文件，不再需要检索目录。此外注意：当前读/写指针等进程私有的访问状态记录在打开文件表表项中，而不是记录在 inode 中，多个进程各自打开同一文件时读写指针互不影响。
