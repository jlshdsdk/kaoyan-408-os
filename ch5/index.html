第5章 输入/输出管理

本章内容较为分散，从 I/O 管理基础（设备分类、I/O 接口、控制方式、软件层次）讲到设备独立性软件（缓冲、分配、SPOOLing），最后落到磁盘和固态硬盘。本章硬件相关知识较多，建议结合《计算机组成原理》的相关内容一起复习；统考中分值虽小，但命题通常较为直接，认真复习者基本能稳拿分。

考纲要求

  1. （一）输入/输出（I/O）管理基础：设备（设备的基本概念、设备的分类、I/O 接口）；I/O 控制方式（轮询方式、中断方式、DMA 方式）；I/O 软件层次结构（中断处理程序、驱动程序、设备独立性软件、用户层 I/O 软件）；输入/输出应用程序接口（字符设备接口、块设备接口、网络设备接口、阻塞/非阻塞 I/O）
  2. （二）设备独立软件：缓冲区管理；设备分配与回收；假脱机技术（SPOOLing）；设备驱动程序接口
  3. （三）外存管理：磁盘（磁盘结构、格式化、分区、磁盘调度算法）；固态硬盘（读/写性能特性、磨损均衡）

复习提示

本章内容较为分散，重点掌握 I/O 接口、I/O 软件、I/O 控制方式、缓冲区管理、SPOOLing 技术，以及磁盘特性与调度算法。由于涉及较多硬件知识，建议结合计算机组成原理的相关内容复习。本章在历年统考中分值较小且命题直接：认真复习者一般能准确作答，未接触相关内容者则难以凭直觉判断——复习务必全面、反复。

章节地图

  • 5.1 I/O管理概述——I/O 设备的分类（块/字符、独占/共享等）与 I/O 接口（设备控制器）的组成，轮询、中断、DMA 三种 I/O 控制方式，I/O 软件四层结构及各类应用程序接口。
  • 5.2 设备独立性软件——设备独立性软件的五项公共功能，单/双/环形缓冲与缓冲池的耗时分析，设备分配中的数据结构与安全分配，SPOOLing 假脱机技术，设备驱动程序接口。
  • 5.3 磁盘和固态硬盘——磁盘的结构与地址组织、格式化与分区，一次磁盘操作的时间构成（寻道、旋转延迟、传输），FCFS/SSTF/SCAN/C-SCAN 等磁盘调度算法，固态硬盘的读写特性与磨损均衡。
  • 5.4 本章疑难点——如何改进设备分配策略（设备无关性与多通路 I/O），用户缓冲区与内核缓冲区的定义及作用。
  • 本章习题——按节整理的选择题与综合应用题，答案可折叠查看。

本章考点分布

  • I/O 控制方式是选择题常客：轮询、中断、DMA 三种方式下 CPU 的介入时机与干预粒度的比较，以及各自适用的传输单位，要求一一分清。
  • I/O 软件四层结构高频考查"某一操作属于哪一层"：中断处理程序、设备驱动程序、设备独立性软件、用户层 I/O 软件的职责边界要能准确判断。
  • 缓冲区管理：单缓冲、双缓冲处理一块数据的总耗时计算常以选择题甚至小综合题出现；SPOOLing 技术如何把独占设备改造成共享设备也是常考点。
  • 磁盘调度算法是本章经典综合题：SSTF、SCAN、C-SCAN 等算法的寻道轨迹与移动道数要能逐步累加算出，选择题也常比较各算法的优劣与饥饿表现。
  • 磁盘时间构成与固态硬盘：寻道时间、旋转延迟、传输时间的计算偶有考查；固态硬盘"读快写慢、以页为单位写、磨损均衡"的特点近年偶尔进入选择题。
