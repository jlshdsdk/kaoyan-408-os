5.1 I/O 管理概述 · 选择题

第 1 题 以下关于设备属性的叙述中，正确的是（　）。

A. 字符设备的基本特征是可寻址到字节，即能指定读/写操作的字节地址
B. 共享设备必须是可寻址的和可随机访问的设备
C. 共享设备是指同一时刻内允许多个进程同时访问的设备
D. 在分配共享设备和独占设备时都可能引起进程死锁

查看答案与解析

答案：B

解析：可寻址（可按字节地址访问）是块设备的基本特征，字符设备如键盘、打印机不可寻址，A 错误。若共享设备不可寻址、不可随机访问，则多个进程交替访问时无法保证数据的完整性和一致性，也无法提高设备利用率，故共享设备必须是可寻址且可随机访问的，B 正确。共享设备是指一段时间内允许多个进程同时（交替）访问的设备，而非"同一时刻"，C 错误。分配共享设备不会引起进程死锁，分配独占设备才可能引起死锁，D 错误。

第 2 题 下列关于虚拟设备的含义的描述中，正确的是（　）。

A. 允许用户使用比系统中具有的物理设备更多的设备
B. 允许用户以标准化方式来使用物理设备
C. 把一个物理设备变换成多个对应的逻辑设备
D. 允许用户程序不必全部装入主存便可使用系统中的设备

查看答案与解析

答案：C

解析：虚拟设备是指采用虚拟技术把一台物理上的独占设备变换成若干台对应的逻辑设备，故选 C。A 错误：用户"感觉"可用的设备变多只是逻辑上的效果，物理设备的数量并未增加，虚拟设备是逻辑概念而非物理地变成共享设备；B 描述的是设备独立性（以标准化、统一的方式使用设备）的作用；D 描述的是虚拟存储技术的效果，与设备无关。

第 3 题 磁盘设备的 I/O 控制主要采取（　）方式。

A. 位　B. 字节　C. 帧　D. DMA

查看答案与解析

答案：D

解析：磁盘是典型的块设备，数据交换以数据块为单位且传输速率高，主要采用 DMA 方式进行 I/O 控制，故选 D。位、字节、帧都不是针对磁盘成块数据传输的 I/O 控制方式：按字节控制只适合低速字符设备，帧是数据链路层的传输单位，与 I/O 控制方式的分类无关。

第 4 题 为了便于上层软件的编制，设备控制器通常需要提供（　）。

A. 控制寄存器、状态寄存器和控制命令
B. I/O 地址寄存器、工作方式状态寄存器和控制命令
C. 中断寄存器、控制寄存器和控制命令
D. 控制寄存器、编程空间和控制逻辑寄存器

查看答案与解析

答案：A

解析：控制寄存器用于接收上层发来的命令，状态寄存器用于存放设备状态信号，二者构成设备控制器与上层的接口；同时控制器还提供一组控制命令（由 CPU 发出、设备控制器提供并识别），A 正确。B 错误：并不存在 I/O 地址寄存器；C 错误：中断寄存器位于主机内而非设备控制器中；D 错误：编程空间一般由体系结构和操作系统共同决定，也不存在"控制逻辑寄存器"。

第 5 题 在设备控制器中用于实现设备控制功能的是（　）。

A. CPU　B. 设备控制器与处理器的接口　C. I/O 逻辑　D. 设备控制器与设备的接口

查看答案与解析

答案：C

解析：设备控制器由设备控制器与处理器的接口、I/O 逻辑、设备控制器与设备的接口三部分组成，其中 I/O 逻辑负责接收 CPU 发来的命令并对设备实施控制，是实现设备控制功能的部分，故选 C。接口只负责传输信号，不起控制作用；CPU 是主机部件，不在设备控制器之内。

第 6 题 DMA 方式是在（　）之间建立一条直接数据通路。

A. I/O 设备和主存　B. 两个 I/O 设备　C. I/O 设备和 CPU　D. CPU 和主存

查看答案与解析

答案：A

解析：DMA 方式在 I/O 设备和主存之间建立一条直接数据通路，数据的成批传送不需要 CPU 干预，故选 A。B 错误：两个 I/O 设备之间一般不直接交换数据；C 错误：DMA 的意义正在于绕开 CPU 传送数据，若通路建在设备与 CPU 之间就失去意义；D 错误：CPU 与主存之间本来就有通路，无需 DMA。这条数据通路只是逻辑上的，实际通常通过总线实现。

第 7 题 在操作系统中，（　）指的是一种硬件机制。

A. 通道技术　B. 缓冲池　C. SPOOLing 技术　D. 内存覆盖技术

查看答案与解析

答案：A

解析：通道是一种特殊的处理器，能独立执行通道程序控制 I/O 操作，属于硬件技术，故选 A。缓冲池是在内存中开辟的公用缓冲区域、SPOOLing 是利用输入/输出井和进程模拟脱机 I/O 的软件技术、内存覆盖是通过软件实现的内存扩充技术，三者都以软件方式实现，均不是硬件机制。

第 8 题 若 I/O 设备与存储设备进行数据交换不经过 CPU 来完成，则这种数据交换方式是（　）。

A. 程序查询　B. 中断方式　C. DMA 方式　D. 直接存取方式

查看答案与解析

答案：C

解析：DMA 方式下，设备与内存之间可以成批地进行数据交换而不用 CPU 干预，CPU 只参与预处理和结束处理，故选 C。程序查询方式由 CPU 反复测试设备状态并亲自执行传送指令完成数据交换；中断方式下每次传送仍由 CPU 执行中断服务程序完成，二者都要经过 CPU。"直接存取方式"是磁带、磁盘等设备的存取分类概念，不是一种 I/O 控制方式。

第 9 题 下列关于 DMA 方式的描述中，正确的是（　）。

A. DMA 是一个专门负责输入/输出的处理机
B. 数据传输过程由 DMA 控制器负责，CPU 只在预处理和后处理阶段进行干预
C. CPU 通过程序的方式给出 DMA 可以解释的程序
D. DMA 不需要 CPU 指出所取数据的地址与长度

查看答案与解析

答案：B

解析：DMA 方式下数据传输完全由 DMA 控制器负责，CPU 仅在传输前的预处理和传输结束后的后处理阶段介入，B 正确。A 错误：DMA 是一个控制器而不是处理机（通道才可视为特殊的处理器）；C 错误：CPU 无须给出 DMA 可解释的程序，只需发出一条启动命令并设置 DMA 控制器中相关寄存器的值；D 错误：DMA 需要 CPU 指出所取数据在内存中的地址与长度，这些参数就存放在 DMA 控制器的寄存器中。

第 10 题 计算机系统中，不属于 DMA 控制器的是（　）。

A. 命令/状态寄存器　B. 内存地址寄存器　C. 数据寄存器　D. 堆栈指针寄存器

查看答案与解析

答案：D

解析：DMA 控制器中包含：命令/状态寄存器（接收 CPU 命令并向 CPU 反映当前状态）、内存地址寄存器（存放本次传输的源地址/目标地址）、数据寄存器（存放待传送的数据）以及数据计数器等。堆栈指针寄存器是 CPU 中用于支持堆栈操作和程序调用的寄存器，与 DMA 传输无关，不属于 DMA 控制器，故选 D。

第 11 题 DMA 传输前需要进行预处理，传输后需要进行后处理，则下列说法中正确的是（　）。

A. 预处理程序运行在用户态，后处理程序运行在内核态
B. 负责预处理和后处理的进程都是请求 I/O 的进程
C. 预处理阶段不需要 CPU 参与，后处理阶段需要 CPU 参与
D. 预处理阶段请求 I/O 的进程处于运行态，后处理阶段处于阻塞态

查看答案与解析

答案：D

解析：预处理由请求 I/O 的进程通过系统调用进入内核态执行驱动程序完成（设置传输参数、初始化 DMA 控制器），之后该进程阻塞自身；传输结束时 CPU 执行中断服务例程做后处理，此时请求 I/O 的进程仍处于阻塞态，D 正确。A 错误：预处理和后处理都在内核态进行；B 错误：后处理由中断服务例程完成，中断服务例程不是一个单独的进程，更不是请求 I/O 的进程；C 错误：预处理阶段 CPU 需执行设备驱动程序来设置相关传输参数，同样需要 CPU 参与。

第 12 题 在下列问题中，（　）不是设备分配中应考虑的问题。

A. 及时性　B. 设备的固有属性　C. 设备独立性　D. 安全性

查看答案与解析

答案：A

解析：设备分配时应考虑：设备的固有属性（决定设备可采用的分配方式，如独占、共享、可虚拟）、设备独立性（提高设备分配的灵活性和利用率）、设备安全性（保证分配设备时不会导致死锁或永久阻塞）。及时性是与系统性能和用户需求相关的因素，设备分配一般无须考虑，它关注的是如何在保证系统安全、正确运行的前提下合理分配和利用设备资源，故选 A。

第 13 题 将系统中的每台设备按某种原则统一进行编号，这些编号作为区分硬件和识别设备的代号，该编号称为设备的（　）。

A. 绝对号　B. 相对号　C. 类型号　D. 符号

查看答案与解析

答案：A

解析：系统为每台物理设备确定一个全系统统一的编号，以便区分和识别设备，这个编号称为设备的绝对号，故选 A。相对号是用户（进程）程序中对自己申请使用的同类设备的编号，须再经系统映射到绝对号；类型号、符号都不是设备管理中用于唯一标识每台物理设备的代号。

第 14 题 关于通道、设备控制器和设备之间的关系，以下叙述中正确的是（　）。

A. 设备控制器和通道可以分别控制设备
B. 对于同一组输入/输出命令，设备控制器、通道和设备可以并行工作
C. 通道控制设备控制器、设备控制器控制设备工作
D. 以上答案都不对

查看答案与解析

答案：C

解析：CPU → 通道 → 设备控制器 → 设备的控制关系层层递进：通道控制设备控制器，设备控制器直接控制设备工作，故 C 正确。A 错误：设备控制器受通道控制，二者不是各自独立地控制设备；B 错误：对于同一组输入/输出命令，要么 CPU 把命令交给通道执行，要么 CPU 直接命令设备控制器执行，二者不存在并行的可能，因此 D 也不成立。

第 15 题 一个计算机系统配置了 2 台相同类型的绘图机和 3 台相同类型的打印机，为了正确驱动这些设备，系统应该提供（　）个设备驱动程序。

A. 5　B. 3　C. 2　D. 1

查看答案与解析

答案：C

解析：设备驱动程序按设备类型配置，每类设备只需一个驱动程序，同类型的各台设备共用。绘图机和打印机属于两种不同类型的设备，工作原理和驱动方式不同，因此系统只需提供 2 个设备驱动程序（绘图机类 1 个供 2 台共用，打印机类 1 个供 3 台共用），与设备的台数无关，故选 C。

第 16 题 将系统调用参数翻译成设备操作命令的工作由（　）完成。

A. 用户层 I/O　B. 设备无关的操作系统软件　C. 中断处理　D. 设备驱动程序

查看答案与解析

答案：B

解析：设备无关的操作系统软件（设备独立性软件）向上层提供系统调用接口，负责把系统调用及其参数翻译成相应的设备操作命令，并根据设备类型选择和调用相应的驱动程序，故选 B。用户层 I/O 只是借助库函数发起系统调用；设备驱动程序负责执行操作系统发出的 I/O 命令，因设备不同而不同，不承担参数翻译工作；中断处理只负责 I/O 完成后的善后处理。

第 17 题 向设备寄存器的写命令是在 I/O 软件的（　）中完成的。

A. 用户层软件　B. 设备独立性软件　C. 设备驱动程序　D. 中断处理程序

查看答案与解析

答案：C

解析：设备驱动程序负责将上层软件发来的抽象 I/O 要求转换为设备控制器能识别的具体要求，并通过向设备寄存器写入命令来控制设备的工作状态和数据传输方式，故选 C。用户层软件和设备独立性软件处理的是与设备无关的抽象请求，不直接接触设备寄存器；中断处理程序负责 I/O 完成后的处理，也不向寄存器写控制命令。

第 18 题 一个典型的文本打印页面有 50 行，每行 80 个字符，假定一台标准的打印机每分钟能打印 6 页，向打印机的输出寄存器中写一个字符的时间很短，可忽略不计。若每打印一个字符都需要花费 \(50\,\mu s\) 的中断处理时间（包括所有服务），则使用中断驱动 I/O 方式运行这台打印机，中断的系统开销占 CPU 的百分比为（　）。

A. 2%　B. 5%　C. 20%　D. 50%

查看答案与解析

答案：A

解析：每分钟打印的字符数为 50 行 × 80 字符/行 × 6 页 = 24000 个字符，即每秒打印 \(24000 \div 60 = 400\) 个字符。每个字符的中断处理需 50μs，故每秒用于中断的系统开销为 \(400 \times 50\,\mu s = 20000\,\mu s = 20\,ms\)。每秒共 1000ms，中断开销占 CPU 的 \(20\,ms \div 1000\,ms = 2\%\)，故选 A。其余 980ms 的 CPU 时间仍可用于其他处理。

第 19 题 在接收和处理一个输入设备的中断的过程中，一定不由硬件来完成的工作是（　）。

A. 判断产生中断的类型　B. CPU 模式由用户态切换到内核态
C. 主机获取设备输入　D. 保存用户程序的断点

查看答案与解析

答案：C

解析：在中断 I/O 方式下，数据的输入和输出由中断服务程序（软件）完成，主机获取设备输入一定由软件实现，故选 C。中断源的识别（判断中断类型）可采用硬件（中断控制器/排队器）识别法；中断响应阶段由硬件完成 CPU 从用户态到内核态的切换并保存用户程序的断点，故 A、B、D 都可以由硬件完成。

第 20 题 下列几种 I/O 方式中，会导致用户进程进入阻塞态的是（　）。
Ⅰ. 程序直接控制　　Ⅱ. 中断方式　　Ⅲ. DMA 方式

A. 仅Ⅱ　B. Ⅰ、Ⅲ　C. Ⅱ、Ⅲ　D. Ⅰ、Ⅱ、Ⅲ

查看答案与解析

答案：C

解析：程序直接控制方式下，用户进程在 I/O 过程中循环测试设备状态而不被阻塞，CPU 与 I/O 严格串行，Ⅰ不符合；中断控制方式下，驱动程序启动第一次 I/O 操作后便调出其他进程执行，当前用户进程被阻塞，Ⅱ符合；DMA 方式下，驱动程序对 DMA 控制器初始化并发出"启动 DMA"命令后即转向其他进程执行，当前用户进程同样被阻塞，CPU 与数据传送并行，Ⅲ符合。故选 C。

第 21 题 当一个进程请求 I/O 操作时，该进程将被挂起，直到 I/O 设备完成 I/O 操作后，设备控制器便向 CPU 发送一个中断请求，CPU 响应后便转向中断处理程序。下列关于中断处理程序的说法中，错误的是（　）。

A. 中断处理程序将设备控制器中的数据传送到内存的缓冲区（读入），或将要输出的数据传送到设备控制器（输出）
B. 对于不同的设备，有不同的中断处理程序
C. 中断处理结束后，需要恢复 CPU 现场，此时一定会返回到被中断的进程
D. I/O 操作完成后，驱动程序必须检查本次 I/O 操作中是否发生了错误

查看答案与解析

答案：C

解析：中断处理结束后是否返回被中断的进程要分情况：若采用屏蔽中断方式（单重中断），处理完毕返回被中断的进程；若采用中断嵌套方式（多重中断），当没有更高优先级的中断请求时才返回被中断的进程，否则系统将先转去处理更高优先级的中断请求，故"一定返回被中断进程"的说法过于绝对，C 错误。A、B、D 均正确：中断处理程序负责在设备控制器与内存缓冲区之间传送数据；不同设备类型对应不同的中断处理程序；I/O 完成后驱动程序必须检查本次操作有无错误。

第 22 题 在 I/O 系统与高层之间的接口中，根据设备类型的不同，又进一步分为若干类接口。若某设备的数据传输速率较高，且可寻址，则比较适合采用（　）。

A. 块设备接口　B. 网络设备接口　C. 字符设备接口　D. 流设备接口

查看答案与解析

答案：A

解析：块设备的数据存取和传输以数据块为单位，特征是传输速率较高且可寻址（能随机读/写任一块），典型代表是磁盘，通常采用 DMA 方式，对应块设备接口，故选 A。字符设备（也称流设备）以字符为单位存取和传输数据，速率较低且不可寻址，如键盘、打印机，对应字符设备（流设备）接口，C、D 与题意相反；B 网络设备接口不属于按此标准的设备类型分类接口。

第 23 题【2010 统考真题】本地用户通过键盘登录系统时，首先获得键盘输入信息的程序是（　）。

A. 命令解释程序　B. 中断处理程序　C. 系统调用服务程序　D. 用户登录程序

查看答案与解析

答案：B

解析：键盘是典型的采用中断驱动 I/O 方式工作的外设。当用户按键输入信息时，键盘控制器向 CPU 发出中断请求，CPU 响应中断后最先由中断处理程序取得键盘输入信息，之后再逐层上交给系统调用服务程序、命令解释程序等处理，故选 B。命令解释程序和用户登录程序只能在输入信息已被接收之后才处理它，不可能"首先获得"。

第 24 题【2011 统考真题】用户程序发出磁盘 I/O 请求后，系统的正确处理流程是（　）。

A. 用户程序 → 系统调用处理程序 → 中断处理程序 → 设备驱动程序
B. 用户程序 → 系统调用处理程序 → 设备驱动程序 → 中断处理程序
C. 用户程序 → 设备驱动程序 → 系统调用处理程序 → 中断处理程序
D. 用户程序 → 设备驱动程序 → 中断处理程序 → 系统调用处理程序

查看答案与解析

答案：B

解析：用户程序发出 I/O 请求时先执行系统调用进入内核，由系统调用处理程序（设备无关软件）处理调用请求，再转到相应的设备驱动程序去启动设备；当设备准备好或所需数据到达后，设备硬件发出中断，由中断处理程序完成善后，数据再按相反顺序逐层回传到用户程序，故流程为"用户程序 → 系统调用处理程序 → 设备驱动程序 → 中断处理程序"，选 B。中断处理位于流程最后，A、C、D 的层次顺序均不符合。

第 25 题【2012 统考真题】操作系统的 I/O 子系统通常由 4 个层次组成，每层明确定义了与邻近层次的接口，其合理的层次组织排列顺序是（　）。

A. 用户级 I/O 软件、设备无关软件、设备驱动程序、中断处理程序
B. 用户级 I/O 软件、设备无关软件、中断处理程序、设备驱动程序
C. 用户级 I/O 软件、设备驱动程序、设备无关软件、中断处理程序
D. 用户级 I/O 软件、中断处理程序、设备无关软件、设备驱动程序

查看答案与解析

答案：A

解析：I/O 软件自上而下分为 4 层：用户层 I/O 软件（库函数等）→ 与设备无关的软件（系统调用处理层）→ 设备驱动程序 → 中断处理程序。请求自上而下逐层传递、结果自下而上逐层返回，设备驱动程序直接与硬件（设备控制器）打交道，中断处理程序在最底层负责 I/O 完成后的处理，故选 A。

第 26 题【2017 统考真题】系统将数据从磁盘读到内存的过程包括以下操作：
① DMA 控制器发出中断请求
② 初始化 DMA 控制器并启动磁盘
③ 从磁盘传输一块数据到内存缓冲区
④ 执行"DMA 结束"中断服务程序
正确的执行顺序是（　）。

A. ①→③→②→④　B. ②→③→①→④　C. ②→①→③→④　D. ①→②→④→③

查看答案与解析

答案：B

解析：DMA 的传送过程分为预处理、数据传送和后处理三个阶段。预处理阶段由 CPU 初始化 DMA 控制器中的有关寄存器、设置传送方向并启动磁盘（②）；数据传送阶段完全由 DMA 控制器控制，从磁盘把一块数据传送到内存缓冲区（③）；传送结束后进入后处理阶段，DMA 控制器向 CPU 发出中断请求（①），CPU 执行"DMA 结束"中断服务程序（④）。故正确顺序为 ②③①④，选 B。

第 1 题 设备的独立性是指（　）。

A. 设备独立于计算机系统　B. 系统对设备的管理是独立的
C. 用户编程时使用的设备与实际使用的设备无关　D. 每台设备都有唯一的编号

查看答案与解析

答案：C

解析：设备独立性（设备无关性）是指用户编程和程序运行时所使用的设备与实际使用的物理设备无关，用户只需用逻辑设备名申请设备，系统负责将其映射到具体的物理设备，故选 C。A 错误：设备是计算机系统的组成部分，谈不上独立于计算机系统；B 错误：系统对设备的管理是统一进行的；D 描述的是设备的绝对号，与设备独立性无关。

第 2 题 引入高速缓冲的主要目的是（　）。

A. 提高 CPU 的利用率　B. 提高 I/O 设备的利用率
C. 改善 CPU 与 I/O 设备速度不匹配的问题　D. 节省内存

查看答案与解析

答案：C

解析：CPU 与 I/O 设备的执行速度通常不对等——前者快、后者慢，引入高速缓冲（缓冲区）的主要目的就是缓和 CPU 与 I/O 设备速度不匹配的矛盾，故选 C。提高 CPU 和 I/O 设备的利用率（A、B）只是引入缓冲后带来的间接效果，而非主要目的；缓冲区本身要占用存储空间，不仅不节省内存，反而占用内存（D 错误）。

第 3 题 为了使多个并发进程能有效地进行输入和输出，最好采用（　）结构的缓冲技术。

A. 缓冲池　B. 循环缓冲　C. 单缓冲　D. 双缓冲

查看答案与解析

答案：A

解析：缓冲池是系统的共用资源，可供多个进程共享，既能用于输入又能用于输出，其中一般包含空闲缓冲区、装满输入数据的缓冲区和装满输出数据的缓冲区三类，并将同类缓冲区链成队列管理，故选 A。单缓冲、双缓冲、循环缓冲属于专用缓冲，只为特定的进程或设备服务，难以同时满足多个并发进程的输入输出需求。

第 4 题 缓冲技术中的缓冲池在（　）中。

A. 主存　B. 外存　C. ROM　D. 寄存器

查看答案与解析

答案：A

解析：由于 CPU 的速度比 I/O 设备高很多，缓冲池通常建立在主存中，以高速的主存区域缓和 CPU 与慢速设备之间的速度矛盾，故选 A。外存（磁盘）上开辟的是 SPOOLing 系统中的输入井和输出井，不是缓冲池；ROM 是只读存储器，不能用于数据缓冲；寄存器容量太小，只能构成个别的硬件缓冲，不是缓冲池。

第 5 题 支持双向传送的设备应使用（　）。

A. 单缓冲区　B. 双缓冲区　C. 多缓冲区　D. 缓冲池

查看答案与解析

答案：B

解析：支持双向收发数据的设备（如网卡）应使用双缓冲区：一个缓冲区用于发送、另一个用于接收，可实现同一时刻的双向数据传输，提高设备的效率和利用率，故选 B。单缓冲区在同一时刻只能实现单向数据传输；多缓冲区和缓冲池是提高 I/O 性能的技术，并非针对"双向传送"的必要配置，不适合作为该题的对应答案。

第 6 题 下列关于缓冲区的描述中，正确的是（　）。

A. 缓冲区是一种专门的硬件缓冲器，不能用内存来实现
B. 缓冲区的作用是提高 CPU 和 I/O 设备之间的速度匹配
C. 缓冲区只能用于输入设备，不能用于输出设备
D. 缓冲区只能用于块设备，不能用于字符设备

查看答案与解析

答案：B

解析：缓冲区是一个存储区域，既可以由专门的硬件寄存器组成，也可以利用内存来实现，A 错误。缓冲区的作用正是缓和 CPU（高速）与 I/O 设备（低速）之间的速度矛盾，避免 CPU 频繁等待设备，B 正确。缓冲区既可用于输入也可用于输出（如键盘输入缓冲、打印机输出缓冲），既可用于块设备（如磁盘）也可用于字符设备（如串口），C、D 错误。

第 7 题 使用单缓冲或双缓冲进行通信时，（　）可以实现数据的双向并行传输。

A. 只有单缓冲　B. 只有双缓冲　C. 都可以　D. 都不可以

查看答案与解析

答案：B

解析：两个进程之间若只设置单缓冲区，同一时刻只能实现单向传输，另一方向的数据只能在一段时间内分时进行，收发无法并行；若设置双缓冲区，一个缓冲区专门用于发送、另一个专门用于接收，即可实现双向同时的并行传输，故选 B。

第 8 题 下列各种算法中，（　）是设备分配常用的一种算法。

A. 首次适应　B. 时间片分配　C. 最佳适应　D. 先来先服务

查看答案与解析

答案：D

解析：设备分配常用的算法是先来先服务算法和最高优先级优先算法，故选 D。首次适应和最佳适应是动态分区分配（内存管理）的常用算法；时间片分配是进程（处理机）调度的常用算法，它们都不是设备分配算法。

第 9 题 设从磁盘将一块数据传送到缓冲区所用的时间为 80μs，将缓冲区中的数据传送到用户区所用的时间为 40μs，CPU 处理一个数据块所用的时间为 30μs。若有多块数据需要处理，并采用单缓冲区传送某磁盘数据，则处理一块数据所用的总时间为（　）。

A. 120μs　B. 110μs　C. 150μs　D. 70μs

查看答案与解析

答案：A

解析：单缓冲方式下，设备与处理机对缓冲区的操作是串行的，而"磁盘 → 缓冲区"的读入（80μs）可与"CPU 处理上一块数据"（30μs）并行，但这两项都必须与"缓冲区 → 用户区"的传送（40μs）串行进行。因此处理一块数据的总时间 = max(80μs, 30μs) + 40μs = 80μs + 40μs = 120μs，故选 A。

第 10 题 某操作系统采用双缓冲区传送磁盘上的数据。设从磁盘将数据传送到缓冲区所用的时间为 \(T_1\)，将缓冲区中的数据传送到用户区所用的时间为 \(T_2\)，CPU 处理一块数据所用的时间为 \(T_3\)，假设一个磁盘块和一个缓冲区的大小相等，某系统在一段时间内连续处理一大批数据，则平均处理一个磁盘块数据的时间为（　）。

A. \(T_1 + T_2 + T_3\)　B. \(\max(T_2, T_3) + T_1\)
C. \(\max(T_1, T_3) + T_2\)　D. \(\max(T_1, T_2 + T_3)\)

查看答案与解析

答案：D

解析：双缓冲下设系统初始状态：缓冲区 1 满、缓冲区 2 空、用户区为空。一个周期内：① \(0 \sim T_2\) 时段，将缓冲区 1 中的数据送入用户区；② \(T_2 \sim T_2+T_3\) 时段，CPU 处理用户区中的数据；③ \(0 \sim T_1\) 时段，磁盘将下一块数据读入缓冲区 2。②和③可以并行，但只有二者都完成后系统才回到初始状态、开始处理下一块，故平均处理一个磁盘块的时间为 \(\max(T_1, T_2 + T_3)\)，选 D。选项 C 是单缓冲情形下的公式。

第 11 题 若 I/O 所花费的时间比 CPU 的处理时间短得多，则缓冲区（　）。

A. 最有效　B. 几乎无效　C. 均衡　D. 以上答案都不对

查看答案与解析

答案：B

解析：缓冲区主要解决输入/输出速度比 CPU 处理速度慢而造成的数据积压问题。当 I/O 花费的时间远短于 CPU 处理时间时，设备不会成为系统瓶颈，数据无需暂存，设置缓冲区几乎没有收益，反而要付出额外的管理和开销，故此时缓冲区几乎无效，选 B。

第 12 题 缓冲区管理者主要考虑的问题是（　）。

A. 选择缓冲区的大小　B. 决定缓冲区的数量　C. 实现进程访问缓冲区的同步　D. 限制进程的数量

查看答案与解析

解析：缓冲区是一种临界资源，无论是单缓冲、多缓冲还是缓冲池，多个进程在使用缓冲区时都存在申请和释放（互斥）的问题，因此缓冲区管理者主要考虑的是实现进程对缓冲区访问的同步与互斥，故选 C。缓冲区大小和数量属于系统配置参数，不是管理中最核心的问题；进程数量更是与缓冲管理无关的因素。

第 13 题 考虑单用户计算机上的下列 I/O 操作，需要使用缓冲技术的是（　）。

第 14 题 以下（　）不属于设备管理数据结构。

第 15 题 下列（　）不是设备的分配方式。

第 16 题 设备分配程序需要访问一系列的数据结构来给进程分配设备，这些数据结构有：设备控制表（DCT）、控制器控制表（COCT）、通道控制表（CHCT）、系统设备表（SDT）。在设备分配的过程中，访问这些数据结构的正确顺序是（　）。

A. SDT → DCT → COCT → CHCT　B. DCT → COCT → CHCT → SDT
C. SDT → COCT → CHCT → DCT　D. COCT → CHCT → SDT → DCT

查看答案与解析

第 17 题 下面设备中属于共享设备的是（　）。

第 18 题 提高单机资源利用率的关键技术是（　）。

第 36 题【2009 统考真题】单处理机系统中，可并行的是（　）。

第 38 题【2011 统考真题】某文件占 10 个磁盘块，现要把该文件的磁盘块逐个读入主存缓冲区，并且送到用户区进行分析，假设一个缓冲区与一个磁盘块大小相同，把一个磁盘块读入缓冲区的时间为 100μs，将缓冲区的数据传送到用户区的时间是 50μs，CPU 对一块数据进行分析的时间为 50μs。在单缓冲区和双缓冲区结构下，读入并分析完该文件的时间分别是（　）。

第 7 题 在磁盘中读取数据的下列时间中，影响最大的是（）。

查看答案与解析

答案：D

解析：一次磁盘读/写的时间由寻道时间、旋转延迟和传输时间组成。寻道要移动磁头臂，是机械运动，耗时最长，在存取时间中占的比例最大，因此对读/写时间的影响最大。旋转延迟（延迟时间）通常少于转一圈的时间，传输时间由转速和数据量决定，都比寻道时间小。

解析：每道的所有扇区组成一个簇，读/写时磁头先寻道找到磁道（平均寻道时间 \(T\) 秒），再旋转读/写完整个磁道（耗时一圈，即 \(r\) 秒），故访问一个磁道共需 \(T+r\) 秒。读/写 \(b\) 字节共占用 \(b/N\) 个磁道（簇），随机寻道时每个磁道都要重新寻道，所以总平均访问时间为 \((r+T)\times b/N\) 秒。

第 24 题 下列关于固态硬盘（SSD）的说法中，错误的是（）。

A. 基于闪存的存储技术　B. 随机读/写性能明显高于磁盘　C. 随机写比较慢　D. 不易磨损

第 25 题 下列关于固态硬盘的说法中，正确的是（）。

B. 相比常规硬盘，固态硬盘优势主要体现在连续存取的速度
C. 静态磨损均衡算法通常比动态磨损均衡算法的表现更优秀

B. 固态硬盘需要进行磨损均衡，而常规硬盘不需要

5.1 I/O 管理概述 · 综合应用题

第 1 题 某计算机系统中，时钟中断处理程序每次执行时间为 2ms（包括进程切换开销）。若时钟中断频率为 60Hz，则 CPU 用于时钟中断处理的时间比率为多少？

查看答案与解析

答案：12%

解析：时钟中断频率为 60Hz，即每秒产生 60 次中断，中断周期为 \(1/60\ \text{s} \approx 16.7\text{ ms}\)。每个中断周期内用于中断处理的时间为 2ms = 0.002s，因此时间比率为

\(0.002\text{ s} \div \dfrac{1}{60}\text{ s} = 0.002 \times 60 = 0.12 = 12\%\)。

即 CPU 有 12% 的时间花费在时钟中断处理上。

第 2 题 考虑 56kb/s 调制解调器的性能：驱动程序输出一个字符后就阻塞，当一个字符打印完毕后产生一个中断，通知阻塞的驱动程序输出下一个字符，然后再次阻塞。若发消息、输出一个字符和阻塞的时间总和为 0.1ms，则由于处理调制解调器而占用的 CPU 时间比率是多少？假设每个字符有一个开始位和一个结束位，共占 10 位。

查看答案与解析

答案：56%

解析：一个字符占 10 位，在 56kb/s（56000 b/s）的速率下，每秒传送的字符数为

\(56000\ \text{b/s} \div 10\ \text{b/字符} = 5600\ \text{字符/s}\)。

即每秒产生 5600 次中断。每次中断需占用 CPU 0.1ms，因此每秒处理调制解调器占用的 CPU 时间为

\(5600 \times 0.1\text{ ms} = 560\text{ ms}\)。

占 CPU 时间的比率为 \(560\text{ ms} \div 1000\text{ ms} = 56\%\)。

第 2 题 在某系统中，若采用双缓冲区（每个缓冲区可存放一个数据块），将一个数据块从磁盘传送到缓冲区的时间为 80μs，从缓冲区传送到用户区的时间为 20μs，CPU 计算一块数据的时间为 50μs。总共处理 4 个数据块，每个数据块的平均处理时间是多少？

查看答案与解析

答案：总耗时 390μs，每块平均处理时间 390μs ÷ 4 = 97.5μs。

记 \(T = 80\text{ μs}\)（磁盘→缓冲区），\(M = 20\text{ μs}\)（缓冲区→用户区），\(C = 50\text{ μs}\)（CPU 计算）。双缓冲时两个缓冲区交替使用：磁盘向缓冲区 2 输入下一块的同时，缓冲区 1 的数据可送入用户区并由 CPU 计算，即 \(T\) 与 \(M+C\) 可并行。逐段时间线（单位 μs）如下：

阶段第 1 块第 2 块第 3 块第 4 块
磁盘 → 缓冲区（T）0～8080～160160～240240～320
缓冲区 → 用户区（M）80～100160～180240～260320～340
CPU 计算（C）100～150180～230260～310340～390

可见从第 2 块起系统进入稳态：每块耗时由磁盘输入 \(T=80\text{ μs}\) 决定（\(\max(T,\ C+M) = \max(80, 50+20) = 80\text{ μs}\)，磁盘输入更慢）。处理 n 个数据块的总耗时为

\((80n + 20 + 50)\text{ μs} = (80n + 70)\text{ μs}\)。

当 n = 4 时，总耗时 \(80 \times 4 + 70 = 390\text{ μs}\)，每块平均处理时间为

\(390\text{ μs} \div 4 = 97.5\text{ μs}\)。

当 n 很大时，平均时间 \((80n+70)/n\ \text{μs}\) 趋近 80μs，即受制于较慢的磁盘输入。

第 3 题【2023 统考真题】进程 P 通过执行系统调用从键盘接收一个字符的输入，已知此过程中与进程 P 相关的操作包括：①将进程 P 插入就绪队列；②将进程 P 插入阻塞队列；③将字符从键盘控制器读入系统缓冲区；④启动键盘中断处理程序；⑤进程 P 从系统调用返回；⑥用户在键盘上输入字符。以上编号①～⑥仅用于标记操作，与操作的先后顺序无关。请回答下列问题。

（2）在上述哪个操作之后 CPU 一定从进程 P 切换到其他进程？在上述哪个操作之后 CPU 调度程序才能选中进程 P 执行？

（3）完成上述哪个操作的代码属于键盘驱动程序？

（4）键盘中断处理程序执行时，进程 P 处于什么状态？CPU 是处于内核态还是处于用户态？

查看答案与解析

答案：（1）正确顺序为②→⑥→④→③→①→⑤：①的前一个操作是③、后一个操作是⑤，⑥的后一个操作是④；（2）操作②之后 CPU 一定切换到其他进程，操作①之后调度程序才能选中 P；（3）操作③；（4）P 处于阻塞态，CPU 处于内核态。

解析：（1）以 scanf 函数的执行过程为例：用户进程 P 调用系统调用 read 陷入内核，设备驱动程序完成 I/O 初始化后执行调度程序，②将 P 阻塞并插入阻塞队列；此后用户在键盘上输入字符⑥，外设向 CPU 发出中断请求，CPU 响应后④启动键盘中断处理程序；中断处理程序做简单通用处理后，唤醒具体的键盘驱动程序，由它③将字符从键盘控制器读入系统缓冲区；数据传送完成后唤醒 P 并①将其插入就绪队列；P 获得 CPU 运行后⑤从系统调用返回。故顺序为②→⑥→④→③→①→⑤。

（2）操作②之后，P 已放弃 CPU 进入阻塞态，内核调度其他进程运行，因此此后 CPU 一定从进程 P 切换到其他进程；操作①之后，P 才进入就绪队列，此后 CPU 调度程序才有可能（也唯有此后才能）选中 P 执行。

（3）操作③"将字符从键盘控制器读入系统缓冲区"是与键盘硬件直接相关的具体 I/O 操作，且属于 I/O 初始化后的具体数据读取，其代码属于键盘驱动程序。

（4）键盘中断处理程序执行时，P 还在阻塞队列中等待数据，处于阻塞态。中断处理程序、设备驱动程序、设备独立性软件都属于内核 I/O 软件层，执行这些代码时 CPU 处于内核态。

第 1 题 假定有一个磁盘组共有 100 个柱面，每个柱面有 8 个磁道，每个磁道划分成 8 个扇区。现有一个 5000 条逻辑记录的文件，逻辑记录的大小与扇区大小相等，该文件以顺序结构被存放在磁盘组上。柱面、磁道、扇区均从 0 开始编址，逻辑记录的编号从 0 开始，文件信息从 0 柱面、0 磁道、0 扇区开始存放。试问：该文件编号为 3468 的逻辑记录应存放在哪个柱面的第几个磁道的第几个扇区上？

查看答案与解析

答案：54 号柱面、第 1 号磁道、第 4 号扇区。

解析：每个柱面有 \(8 \times 8 = 64\) 条逻辑记录（8 个盘面 × 每面 8 个扇区）。由于所有磁头固定在一起同步移动，存放时顺序是：先存满一个磁道的各扇区，再存满同一柱面的各磁道，最后才移到下一柱面。逐步换算（除法向下取整）：

柱面号 = ⌊3468 ÷ 64⌋ = 54          （54 × 64 = 3456 ≤ 3468）
余下记录数 = 3468 mod 64 = 12
磁道号 = ⌊12 ÷ 8⌋ = 1
扇区号 = 12 mod 8 = 4

因此，编号为 3468 的逻辑记录应存放在 54 号柱面、1 号磁道、4 号扇区。

第 2 题 假设磁盘的每个磁道分成 9 个块，现在一个文件有 A,B,…,I 共 9 条记录，每条记录的大小与块的大小相等。设磁盘转速为 27 毫秒/转，每读出一块后需要 2ms 的处理时间。若忽略其他辅助时间，且一开始磁头在即将要读 A 记录的位置，试问：

（1）若将这些记录顺序存放在一个磁道上，则顺序读取该文件要多少时间？

\(8 \times (27 + 3) + (3 + 2) = 240 + 5 = 245\text{ ms}\)。

\(3\text{（读出）} + 2\text{（处理）} + 1\text{（等待）} = 6\text{ ms}\)。

处理 9 条记录的总时间为

\(6 \times 8 + (3 + 2) = 48 + 5 = 53\text{ ms}\)。

第 4 题 某软盘有 40 个磁道，磁头从一个磁道移至相邻磁道需要 6ms。文件在磁盘上非连续存放，逻辑上相邻数据块的平均距离为 13 磁道，每块的旋转延迟时间及传输时间分别为 100ms 和 25ms。问读取一个 100 块的文件需要多少时间？若系统对磁盘进行了整理，让同一文件的磁盘块尽可能靠拢，从而使逻辑上相邻数据块的平均距离降为 2 磁道，这时读取一个 100 块的文件需要多少时间？

查看答案与解析

答案：整理前 20300ms，整理后 13700ms。

解析：读取一块数据的时间 = 寻道时间 + 旋转延迟时间 + 传输时间。寻道时间 = 平均移动磁道数 × 相邻磁道移动时间 6ms。

整理前：平均寻道距离 13 磁道，读一块数据需要的时间为

\(13 \times 6\text{ ms} + 100\text{ ms} + 25\text{ ms} = 78 + 100 + 25 = 203\text{ ms}\)。

读取 100 块的文件需要的时间为

\(203\text{ ms} \times 100 = 20300\text{ ms}\)（即 20.3s）。

整理后：平均寻道距离降为 2 磁道，读一块数据需要的时间为

\(2 \times 6\text{ ms} + 100\text{ ms} + 25\text{ ms} = 12 + 100 + 25 = 137\text{ ms}\)。

读取 100 块的文件需要的时间为

\(137\text{ ms} \times 100 = 13700\text{ ms}\)（即 13.7s）。

（1）依次读取一个磁道上的所有扇区需要多少时间？

（2）该磁盘的数据传输速率是多少？

查看答案与解析

答案：（1）70ms（0.07s）；（2）约 58.5KB/s。

解析：逻辑上连续的扇区（如 0、1、2…）在物理上正好相隔 2 个扇区位置——这 2 个扇区通过的时间恰好用来把数据从控制器传送到内存，因此磁头可以不停地连续读，不必专门空等。

（1）旋转速度 3000 转/分 = 50 转/秒，即每转一圈需 \(1 \div 50 = 0.02\text{ s} = 20\text{ ms}\)。

读一个扇区需要的时间：\(20\text{ ms} \div 8 = 2.5\text{ ms}\)。

读一个扇区并把其中数据从控制器送入内存（期间转过 2 个扇区）共需：\(2.5\text{ ms} \times 3 = 7.5\text{ ms}\)（读 1 个 + 传送占 2 个扇区位置）。

\(10\text{ ms} + 8 \times 7.5\text{ ms} = 10 + 60 = 70\text{ ms} = 0.07\text{ s}\)。

（2）每个磁道的数据量为

\(8 \times 512\text{ B} = 4096\text{ B} = 4\text{ KB}\)。

读完一个磁道用时 0.07s，故数据传输速率为

\(4 \times 1024\text{ B} \div (1000 \times 0.07\text{ s}) \approx 58.5\text{ KB/s}\)。

③ 传输时间：每磁道 100 个扇区，转一圈 10ms，故读取一个扇区平均需 \(10\text{ ms} \div 100 = 0.1\text{ ms}\)，4 个扇区共 \(4 \times 0.1\text{ ms} = 0.4\text{ ms}\)。

综上，读完这 4 个扇区共需

\(170\text{ ms} + 20\text{ ms} + 0.4\text{ ms} = 190.4\text{ ms}\)。

（3）有，采用先来先服务（FCFS）调度策略更高效。因为 Flash 半导体存储器没有磁头和盘片等机械部件，不需要考虑寻道时间和旋转延迟，任意位置都能直接随机访问，故按 I/O 请求的先后顺序服务即可，无须再通过 C-SCAN 之类的调度优化寻道。

第 7 题【2019 统考真题】某计算机系统中的磁盘有 300 个柱面，每个柱面有 10 个磁道，每个磁道有 200 个扇区，扇区大小为 512B。文件系统的每个簇包含 2 个扇区。请回答下列问题：

（1）磁盘的容量是多少？

（2）设磁头在 85 号柱面上，此时有 4 个磁盘访问请求，簇号分别为 100260、60005、101660 和 110560。采用最短寻道时间优先（SSTF）调度算法，系统访问簇的先后次序是什么？

（3）簇号 100530 在磁盘上的物理地址是什么？将簇号转换成磁盘物理地址的过程由 I/O 系统的什么程序完成？

查看答案与解析

答案：（1）\(3\times10^5\) KB；（2）100260 → 101660 → 110560 → 60005；（3）柱面号 100、磁头号 5、扇区号 60，由磁盘驱动程序完成。

（1）磁盘容量 = 柱面数 × 每柱面磁道数 × 每磁道扇区数 × 每扇区大小：

\(300 \times 10 \times 200 \times 512\text{ B} = 307200000\text{ B}\)。

换算单位：\(307200000 \div 1024 = 300000\text{ KB} = 3\times10^5\text{ KB}\)。

（2）SSTF 总是访问当前柱面距离最近的请求。每个柱面包含的簇数为

\(10 \times 200 \div 2 = 1000\) 簇，故 85 号柱面对应簇号 85000～85999。

将各请求簇号换算成柱面号（簇号 ÷ 1000，向下取整）：100260 → 100 号柱面；60005 → 60 号柱面；101660 → 101 号柱面；110560 → 110 号柱面。从 85 号柱面出发：各请求距 85 号柱面分别为 15、25、16、25 个柱面，最近的是 100 号柱面（簇 100260）；此后距 100 号柱面最近的是 101 号柱面（1 个柱面，簇 101660）；再是 110 号柱面（9 个柱面，簇 110560）；最后访问 60 号柱面（簇 60005）。访问次序为

100260 → 101660 → 110560 → 60005。

（3）簇号 100530 的物理地址由柱面号、磁头号（盘面号）、扇区号构成，换算规则：除法向下取整（⌊ ⌋），余数继续参与下一步：

柱面号 = ⌊簇号 ÷ 每柱面簇数⌋ = ⌊100530 ÷ (10×200÷2)⌋ = ⌊100530 ÷ 1000⌋ = 100
余数 = 100530 mod 1000 = 530（柱面内簇号）
磁头号 = ⌊柱面内簇号 ÷ 每磁道簇数⌋ = ⌊530 ÷ (200÷2)⌋ = ⌊530 ÷ 100⌋ = 5
扇区号 = (柱面内簇号 × 每簇扇区数) mod 每磁道扇区数 = (530 × 2) mod 200 = 60

因此簇号 100530 的物理地址为：100 号柱面、5 号磁头（盘面）、60 号扇区。将簇号转换成磁盘物理地址的过程由磁盘驱动程序（设备驱动程序）完成。

第 8 题【2021 统考真题】某计算机用硬盘作为启动盘，硬盘的第一个扇区存放主引导记录（MBR），其中包含磁盘引导程序和分区表。磁盘引导程序用于选择引导哪个分区的操作系统，分区表记录硬盘上各分区的位置等描述信息。硬盘被划分成若干分区，每个分区的第一个扇区存放分区引导程序，用于引导该分区中的操作系统。系统采用多阶段引导方式，除了执行磁盘引导程序和分区引导程序，还需要执行 ROM 中的引导程序。回答下列问题：

（1）系统启动过程中操作系统的初始化程序、分区引导程序、ROM 中的引导程序、磁盘引导程序的执行顺序是什么？

（2）把硬盘制作为启动盘时，需要完成操作系统的安装、磁盘的物理格式化、逻辑格式化、对磁盘进行分区，执行这 4 个操作的正确顺序是什么？

（3）磁盘扇区的划分和文件系统根目录的建立分别是在第（2）问的哪个操作中完成的？

查看答案与解析

答案：（1）ROM 中的引导程序 → 磁盘引导程序 → 分区引导程序 → 操作系统的初始化程序；（2）物理格式化 → 分区 → 逻辑格式化 → 操作系统的安装；（3）扇区划分在物理格式化中完成，根目录建立在逻辑格式化中完成。

解析：（1）启动时 CPU 首先执行固化在 ROM 中的引导程序（自举程序），它读入硬盘第一个扇区的主引导记录并执行其中的磁盘引导程序；磁盘引导程序根据分区表确定引导哪个分区，随后执行该分区的分区引导程序；分区引导程序装入该分区的操作系统并转交控制权，最后执行操作系统的初始化程序完成系统启动。

（2）正确顺序为：磁盘的物理格式化 → 对磁盘进行分区 → 逻辑格式化 → 操作系统的安装。物理格式化（低级格式化，通常出厂时已完成）为每个磁道划分扇区、安排扇区排列顺序并标记坏扇区；分区把磁盘整体存储空间划分为相互独立的多个分区（如 Windows 的 C 盘、D 盘）；逻辑格式化（高级格式化）建立文件系统的引导记录、文件分配表、根目录与数据区等；磁盘只有经过分区和逻辑格式化后才能安装操作系统和存储信息。

（3）磁盘扇区的划分是在物理格式化中完成的；文件系统根目录的建立是在逻辑格式化中完成的。
